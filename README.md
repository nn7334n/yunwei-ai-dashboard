## 💡 为什么需要它？

本地运行大模型（如 Qwen 2.5、DeepSeek-R1、Llama 3）和私有知识库虽然安全不泄密、无 Token 费用，但普通用户和企业员工常遇到以下痛点：
1. **黑框命令行门槛高**：原生 Ollama 没有直观图形界面，很多非程序员望而却步；
2. **显存长期霸占、电脑卡顿发热**：模型一旦载入常驻显存，普通电脑打游戏或剪视频极度卡顿，不知道怎么单独释放；
3. **选型迷茫**：不清楚自己的 8G/16G/32G 电脑究竟适合跑多大的模型，盲目下拉导致死机；
4. **协同不便**：想让同办公室的手机、iPad 或同事电脑连进来体验，配置复杂网络监听和端口转发极其繁琐。

**云微 AI 控制面板** 就是为解决上述所有问题而生的全能轻量级中枢！

| 维度对比 | 原生 Ollama / 纯命令行 | Docker / 繁重套件 | ⚡ 云微 AI 控制面板 |
| :--- | :--- | :--- | :--- |
| **部署门槛** | 敲复杂命令参数 | 需安装数 GB 的 Docker 环境 | **零三方库依赖，双击批处理即开** |
| **算力感知** | 盲猜，无硬件推荐 | 需手动修改配置文件 | **自动硬件体检，一键推荐黄金组合** |
| **显存控制** | 模型驻留无法单项释放 | 只能强制杀进程 | **单模型启停/秒级显存释放，电脑不卡** |
| **局域网分享** | 需配置 OLLAMA_HOST 等环境变量 | 需复杂端口映射 | **智能提取局域网 IP，同 WiFi 扫码直连** |
| **知识库接入** | 需另外找 UI 并手动配置 | 配置繁琐易报错 | **内置全自动隔离虚拟环境部署 WebUI** |

## ✨ 核心亮点

### 1. 🖥️ 智能硬件算力评测，黄金组合一键装机
- 自动智能读取本机 CPU 架构与物理内存容量（8GB / 16GB / 32GB / 64GB+）；
- 精准测算并推荐当前硬件极限能发挥最大性能的**黄金模型组合**（如 32GB 机器自动匹配 `qwen2.5:14b` + `bge-m3` 向量底座）；
- 支持新手“⚡ 一键部署黄金推荐全家桶”，免去到处挑模型的困扰。

### 2. 🧠 精细化显存管理，告别风扇狂转
- **单模型启停控制**：随用随启，不用时一键退出显存，瞬间归还数 GB 内存；
- **真实硬件状态监控**：直观显示 Ollama 引擎进程状态、已分配显存/内存容量，日常办公轻盈流畅。

### 3. 💬 界面内极速推理演练
- 无需等待打开庞大的聊天界面，在面板中即可直接弹窗向本地模型发送测试提示词；
- 实时统计首字回复速度与耗时秒数（精确到小数点后两位），模型效果好不好一测便知。

### 4. 📱 物理局域网智能识别，多端设备随心用
- 自动过滤 Docker、VPN 等虚拟网卡，识别真实的物理局域网 IPv4 地址；
- 一键复制地址，同局域网下的手机、平板、其他工位电脑无需安装任何软件，浏览器输入即可共享大模型算力。

### 5. 🚀 Open WebUI 一键全自动部署
- 内置自动化脚本与清华源 PyPI 高速镜像，全自动创建独立隔离虚拟环境；
- 小白用户点击按钮即可自动完成 WebUI 图形知识库系统的安装，全程可视化进度条展示。

## 🚀 快速开始

本项目后端采用 **纯 Python 标准库** 编写，前端单文件免编译，**无需执行任何庞大的 `pip install` 依赖**！

### 方式一：Windows 用户（极简一键运行）
1. 下载本项目 Zip 压缩包并解压；
2. 确保电脑已安装 Python 3.8+（安装时请务必勾选 `Add Python to PATH`）；
3. 直接双击运行 **`start.bat`**；
4. 浏览器将自动打开 `http://localhost:9090`，即可开始使用。

### 方式二：macOS / Linux 用户
打开终端，进入项目目录，执行：
```bash
chmod +x start.sh
./start.sh
```
浏览器将自动唤起控制面板。

### 方式三：极客命令行直接启动
```bash
git clone https://github.com/nn7334n/yunwei-ai-dashboard.git
cd yunwei-ai-dashboard
python3 server.py
```
控制台将输出本地及局域网访问地址：
```text
============================================================
  AI 控制面板后台服务已启动 (支持跨平台与局域网多端访问)
  > 本地访问:    http://localhost:9090
  > 局域网访问:  http://192.168.1.108:9090 (手机/平板/同网电脑)
============================================================
```

> **前置要求**：请确保电脑已安装 [Ollama](https://ollama.com/)。若未安装，点击控制面板中的提示链接即可一键前往官网下载。
